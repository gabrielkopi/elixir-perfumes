# Atelier v5

Site estático HTML/CSS/JavaScript publicado no GitHub Pages. Modo claro/escuro/automático, vidro via backdrop-filter e fallback opaco, notas clicáveis e alquimia com correspondência de nomes nas fontes. Expo GlassEffect é nativo de iOS 26 e recua para uma View em plataformas sem suporte; por isso não foi adicionado como dependência inativa a este site.

267 fotografias existentes foram processadas localmente com rembg/u2netp, preservando arquivos de origem. 106 originais WePink foram recuperados para evitar a ampliação da miniatura antiga. As imagens recortadas têm versão de detalhe e miniatura de 480 px, WebP de qualidade alta e alfa. Transparências de vidro e reflexos internos não são uma reconstrução física do produto. Treze registros sem foto continuam sem foto.

Novas ilustrações de notas geradas com o recurso nativo image_gen; PNGs originais permanecem na pasta de geração local e a aplicação usa WebP de 640 px com alfa. O manifesto relaciona cada nota a seu arquivo. Para moléculas e acordes abstratos, a imagem é uma interpretação, sem inventar uma identidade botânica.

Prompt da primeira leva: One premium photorealistic perfume ingredient cutout representing [NOTE]. Correct recognizable subject, extremely crisp macro detail, natural color, soft studio light. Single ingredient composition centered square, isolated on truly transparent background. No text, no other ingredients, no frames. For abstract perfumery accords use an artistic material still life, not fake botanical claims.

Prompt da segunda leva: One photorealistic premium perfumery note illustration for "[NOTE]". For a real botanical or food: correctly recognizable specimen, crisp macro detail. For a synthetic molecule, abstract accord, metallic/mineral/aquatic descriptor or imagined scent: an elegant abstract material still life evoking that exact scent name, never invent a botanical identity. A single centered square composition, transparent background, soft studio lighting, no text or lettering, no frames, no collage.

12 novos perfis e 24 publicações fictícias. Nenhuma nova pessoa real ou ação externa de mensagem. Preferências continuam locais. Pesquisa de notas não prevê uma fórmula nem o aroma de uma mistura física.
